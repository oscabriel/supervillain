# The outbound-only hybrid: drop iroh; the Host dials out to a gateway

Resolved on [Adopt the outbound-only hybrid (#54)](https://github.com/oscabriel/supervillain/issues/54), 2026-07-24 — the ratification of the centralization research sessions, 2026-07-22 → 2026-07-24 (research corpus and per-question decision ledger: `.agents/research/centralization/`, local-only). The founding transport bet — players reach the GM's machine over iroh peer dialing with a relay fleet behind it — was re-examined against the actual evidence: the founding inspiration (ascii-royale) never validated our three-party topology; iroh's benefits reach only our rarest surface (the direct CLI join) while costing our largest complexity block (relays + admission, tickets/n0 discovery, per-platform native artifacts, the Bun→Node→Rust fallback ladder); and n0's relay fleet is now a metered commercial service. Fifteen questions (NQ-1..15) were ratified individually; this ADR records them as one decision.

**Decision: adopt option C — the outbound-only hybrid.** The GM's Host keeps the canonical campaign folder and **dials out** to a gateway over one authenticated connection; remote players reach the gateway, never the Host directly. Only *reachability* centralizes — canonical state stays plain files on the GM's disk, so every "you own your campaign" promise survives verbatim. Killed from launch scope: `transport-iroh`, the relay fleet and admission policy, tickets/n0 discovery, per-platform native transport artifacts, the transport fallback ladder, and the forced-relay CI gate. **The macos-x64 platform-drop ADR and the relay-admission ADR are deleted outright** (their subjects no longer exist; this document is their record); ADR-0001's codec/dial split happens for real (below); ADR-0003's registration and ADR-0005's linking survive with the amendments noted below.

**Decision: the pipe is WebSocket over TLS** (NQ-2). Logical channels are app-level frames over the existing envelope work. The only thing that reopens this: the R9 capacity benchmark or production telemetry showing the single Host pipe saturating, or head-of-line stalls attributable to the transport — a measurement, never novelty.

**Decision: the Host credential is a per-machine key linked through ADR-0005 — no new identity primitive** (NQ-3). The CLI mints an ed25519 keypair on the hosting machine (stored in per-machine config, never the campaign folder — the folder moves, credentials don't); it joins the GM's key-equivalence graph via the ordinary linking-code flow; the gateway authenticates the pipe by challenge-signature and resolves identity through the registry. Rotation = link new, retire old. Two consequences accepted: **revocation graduates from ADR-0005's "deliberately undesigned" to required** (the backend must mark keys revoked; the gateway must refuse them — an always-on homelab box makes key compromise real) _(Correction 2026-07-25, [ADR-0013](./0013-server-data-layer-gateway-owned-identity-and-two-stores.md): **the gateway** marks keys revoked and refuses them — revoked state is a column in the gateway's own store. Assigning it to the backend contradicted NQ-9 below, which leaves a self-hosted gateway with no backend to ask; gateway ownership makes refusal a local read that works with our servers unreachable, which is the point of an always-on box. The gateway also resolves identity locally rather than "through the registry" remotely.)_, and host keys carry **full equivalence at launch** — a scoped host-only role is named hardening, not launch work (the box holding the key also holds the campaign files; scoping protects little the box doesn't already expose).

**Decision: registration splits into durable ownership and live attachment** (NQ-4). Durable: `name → owner identity` in the gateway's SQLite — survives disconnects; ADR-0003's ownership rule widened from registering *key* to owner *identity* (roaming stays free via ADR-0005). Live: `name → current pipe`, memory-only — the routing truth that replaces name→NodeId. `create --name` claims-or-renews then attaches; same identity re-registers freely and always supersedes its own live registration (crash-restart, machine moves); another identity is rejected. Heartbeat: WS ping/pong (~25 s, dead after 2 misses). Offline = pipe detected dead; player sessions get an honest "host offline" notice and a grace window (~5 min) before returning to the lobby. No name expiry at launch (revisit: name contention on the hosted gateway). Numbers are tunable defaults; the shape is the decision.

**Decision: one pipe per Host process; isolation lives at the gateway** (NQ-5). All Rooms and all logical channels (register/info/submit/stream/link — ADR-0005's linking conduit included) multiplex over the one connection as frames tagged (room, channel); Host liveness is one fact. The gateway holds **one shared per-Room fold with per-session views**, each session with its own backpressure budget — a slow reader exhausts only its own buffer, never the Room or the Host pipe. Large payloads chunk into bounded frames with fair per-Room interleaving. The frame protocol is a versioned wire contract in `room-wire`.

**Decision: the pipe auto-reconnects; commands never auto-resubmit; restarts are brief, total, honest; one replica at launch** (NQ-6). The Host redials forever with backoff+jitter (an unattended homelab Host has no human). ADR-0001's never-auto-retry governs submits unchanged: a lost ack surfaces as failed/uncertain with a human retry affordance. `room-wire`'s submission-id dedupe survives — a replayed id never double-appends, so a command lands exactly once or not at all. A gateway deploy drops every pipe and session; Hosts reattach in seconds, players re-ssh by hand; no session preservation at launch — deploy copy owns it. Single gateway replica at launch, deliberately; the one discipline bought now is that the wire contract never assumes process-locality (late.sh's measured horizontal-scaling scar).

**Decision: the CLI is tooling, not a membership card** (NQ-7). Installing it grants abilities — key management, hosting (`create`), publishing, and a convenient door (`join`) — never identity. `join <room>` at launch is a thin front door over SSH: an ordinary SSH session to the configured gateway using the CLI-managed key; no parallel client protocol ships. A native local-render join mode is future work, triggered by measured gateway render cost or latency demand. `create` keeps meaning "this process is the Host" and always works with no gateway and no account; with a gateway configured it additionally dials out and registers. Accepted honestly: at launch `join` adds convenience, not capability, over bare SSH — the pinned verb set survives with this re-pinned meaning. (This is late.sh's exact CLI shape, verified in source: same principal either way; their ephemeral-token local-capability pairing is noted for future device features.)

**Decision: "your key is your account" survives verbatim; the identity is the equivalence class** (NQ-8). The slogan's real content — no signup, no password; presenting a key is logging in; an unknown key becomes an identity on first contact — never depended on iroh. The backend's internal id per equivalence class (the "resolved identity" ADR-0008/0010 already assume) is plumbing and **never user-facing**: no usernames, no account page; a user-facing handle would be a definition patch. The honest loss (r7): key-as-*address* is gone; copy must never imply the cryptographic-reachability half.

**Decision: three self-hosting postures, all first-class** (NQ-9). (1) **Hosted** — the Host dials our gateway; zero setup; the default and the pitch. (2) **Self-hosted gateway** — the *same single compiled binary*, MIT in the open repo, on a VPS or homelab box; this is what keeps "free to self-host, forever" literally true. The homelab ritual is one forwarded port + DDNS, and the exposed protocol is SSH; an always-on home box can run the Host too, dissolving the sleeping-laptop gap for this cohort without hosted authority. (3) **Local/offline** — no gateway. The two promises are stated separately in all copy: data ownership holds in all three postures; connectivity ownership arrives in 2–3. LAN play is posture 2 at distance zero — a docs recipe, not a mechanism (an embedded-door `create` convenience is future sugar, built only if the recipe proves annoying). TLS: the hosted gateway uses real certs; a self-hosted gateway mints a self-signed cert whose fingerprint travels in the Host-onboarding pairing code (SSH-style TOFU) — no CA, domain, or reverse proxy ever required.

**Decision: the hosted gateway is free with protective caps; every number waits for the benchmark** (NQ-10). No paid tier at launch; caps (concurrent rooms per identity, sessions per room, idle timeouts, per-session output budgets) are cost-ceiling and abuse protection, not monetization — outgrowing them has a free first-class exit (posture 2). No cap number or public capacity claim precedes the R9 benchmark (1/10/50/100 sessions; idle/chat/map-pan/slow-reader). At capacity: refuse new sessions at the lobby honestly; never degrade live tables. The business sentence is corrected: hosted is free *deliberately, as the funnel* toward the v3 paid tier — the company carries render+broker cost because zero-setup is the pitch. "Free because self-hosting costs us nothing" is retired from all copy (it is now false); "self-hosting is free because the binary is MIT" survives.

**Decision: no durable game state at the gateway; metadata-only logging; privacy is a policy, stated as one** (NQ-11). The gateway may hold game-derived state **in memory only** (the per-Room fold, reconnect snapshots, session buffers); none of it touches disk or DB — a restart loses only live sessions. The durable store remains the already-pinned list: name registry, key-equivalence graph, presentation prefs, published artifacts, ops/abuse records. _(Attributed 2026-07-25, [ADR-0013](./0013-server-data-layer-gateway-owned-identity-and-two-stores.md): this list names *what* but never *where*, and there are two stores. **Gateway store:** name → owner identity, presentation prefs, the key-equivalence graph, revoked keys, link codes. **Backend store:** published artifacts (documents as files on disk, rows pointing at them), capability tokens, dead-token tombstones. The full itemized table, and the never-durable mirror restated as a testable invariant, live in ADR-0013.)_ Game content — payloads, chat, rolls, sheets, maps — never enters logs, metrics, telemetry, or crash reports (crash paths scrub); allowed exhaust is metadata only (connection lifecycle, counts, sizes, latencies, error codes, and room names as the one accepted user-named string). This paragraph is the never-log list's home. Wording: with iroh died the E2E *property* ("we cannot read your game"); its replacement is a *policy* ("we relay and render your game; we don't store it, and our logs never contain it") — never marketed as E2E. The property remains available by self-hosting, where the only gateway operator is you.

**Decision: the milestone gate becomes the broker suite; the dual lane survives; macOS x64 returns** (NQ-12). Milestone 1's exit criterion is an integration suite mechanizing the rules above: challenge-signature auth incl. revoked-key refusal; claim/renew/attach incl. same-identity takeover; multi-room multi-session multiplexing over one pipe; a slow reader stalling only itself; gateway restart → auto-reattach in seconds; replayed-id dedupe + surfaced no-retry failure; heartbeat → offline → grace → lobby; clean shutdown both ends. The dual Bun/Node lane survives with a new rationale (r6): the event-sourced core stays runtime-portable; only the edges (Table, gateway render, CLI binary) are Bun-bound — `room-host`, `room-wire`, and the broker logic run identical specs under `bun test` and vitest/Node. macOS x64 rejoins the GM platform matrix — the drop's sole blocker (no darwin-x64 iroh artifact) is dead and OpenTUI's Zig lib ships darwin-x64 — conditional on a passing darwin-x64 CI smoke build before any public platform claim.

**Decision: `room-wire` goes transport-neutral; `transport-ws` fills the lattice slot; iroh keeps a named re-entry path** (NQ-13). `room-wire` keeps the envelope codec, submission/dedupe, and RoomStore semantics, gains the frame protocol, and defines all of it over one small abstract connection interface — with a new dependency-cruiser rule: **`room-wire` imports no transport package**. `packages/transport-ws` replaces `transport-iroh`: a thin WS adapter, client half (Host) and server half (gateway-only import), in the Node-compat set so the dual lane covers the real transport; the render side imports neither half. iroh is dropped *from launch scope* with re-entry preserved: a comeback is another adapter behind the same interface, triggered only by measured demand for direct/serverless play (LAN-recipe friction in practice, or privacy demand the logging policy can't satisfy). Counterweight: the interface serves exactly one live transport at launch and may fit it snugly — no iroh concepts (tickets, relay hints) smuggled through "for later."

**Decision: adopt `@opentui/ssh` at the Door, pinned, with prerequisites** (NQ-14). It replaces most hand-rolled ssh2 wiring and brings signature-verified key auth, the promptless-guest path, drain-proof output backpressure, the size clamp, session limits, and clean teardown (verified in source at the pinned clone). Pre-1.0 is accepted with mitigations: exact-version pin, the source clone as API truth, upgrades as deliberate events. Prerequisites: `runChrome` accepts an injected renderer (local TTY keeps its own behind a factory; `chrome.ts:98`) and the ambient `renderer.start()` (`chrome.ts:312`) is removed — **no ambient rendering** is the standing clause; idle CPU is benchmarked after the fix, never assumed. Adoption solves nothing about pre-auth flood control, actor mapping, room routing, or moderation — still ours. Production PTY cap: an ops-tunable below the library's 500×200, default ~300×100, final number R9-gated; oversized terminals get the capped render with an honest notice.

**Decision: option D (hosted authority) gets an instrumented tripwire, not a mood** (NQ-15). The sleeping laptop stays the accepted launch gap, now measured from day one: join attempts landing on offline rooms, mid-session host drops, grace-window expiries — counts only, per the logging policy. The reopening tripwire: over any rolling 30 days, **more than 1 in 5 join attempts to registered rooms land on an offline host**, or churned GMs name host availability as the leading exit reason. Crossing it *opens* the D decision with data; it never auto-builds. The 20% line is a deliberate, ADR-adjustable stake. The counter-signal is counted too: homelab adoption absorbing the always-on cohort. D's admission requirements are pre-committed now: if ever built, hosted authority must itself be self-hostable with a *tested* hosted→self-hosted restore — the company-death test.

**Consequences:** `product-definition.md` gains dated corrections at every iroh-bearing claim (pillars, hosting model, identity, business shape, v0 scope, workspace tree, test discipline, CLI platforms, data edge, milestone 1, scaffold caveats, churn ledger, relay fog — all pointing here). The workspace loses `packages/transport-iroh` and gains `packages/transport-ws`; the dependency-cruiser lattice swaps the slot and adds the room-wire-imports-no-transport rule. `apps/gateway` gains the broker server half and (behind NQ-14's prerequisites) `@opentui/ssh`. The hello-iroh compile smoke and the `.node`-sidecar distribution wrinkle die with the napi artifact — OpenTUI's Zig lib is the binary's only remaining native piece. ADR-0005's registration-connection duties ride the new pipe unchanged. Revocation, the R9 benchmark, and the darwin-x64 smoke build become named work items. The 16 steal-plan DB questions remain open build-time questions — centralizing the transport deleted relays, not obligations. _(Disambiguated 2026-07-25, [ADR-0013](./0013-server-data-layer-gateway-owned-identity-and-two-stores.md): "DB" here is the **DEFINITION BUGS** prefix from `.agents/research/comparative/steal-plan.md` §5 ("DEFINITION BUGS — questions for the owner": moderation vocabulary, backpressure policy, spectators, accessibility) — **not database questions.** Standing next to backend topics in this paragraph, the shorthand has already caused one misreading. It never gated the data-layer decision.)_

**Revisit triggers:** WS→QUIC only on the named transport measurement; iroh re-entry only on the named direct/serverless demand; option D only on the 20%-offline tripwire or its churn-attribution twin; scoped host-only keys when hardening justifies a role concept in the equivalence graph; name expiry on hosted name contention; the native local-render `join` on measured gateway render cost or latency; the embedded LAN door if the recipe proves annoying; session preservation across gateway restarts and multi-replica routing only against production measurements.
