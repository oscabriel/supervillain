title: A wanted poster
kind: clue
---

Nailed to the waymarker a mile before the ford, weathered but legible:

```text
+--------------------------------------+
|              W A N T E D             |
|                                      |
|        the bandit called GALL        |
|       for robbery on the Ford Road   |
|                                      |
|      REWARD   50 silver, alive       |
|               20 silver, otherwise   |
|                                      |
|   ask for the reeve at Brackwater    |
+--------------------------------------+
```

Someone has scratched a lantern into the corner.

## GM Notes

Gall is the bandit chief. The lantern is the buyer's mark; it turns up again in the ledger.
